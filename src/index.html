Online Java Sandbox

What actually happens between clicking “Run” and seeing Java code execute on a server? I built this sandbox to find out. It’s an evolving prototype: a browser editor, a Java backend and disposable Docker containers, running on my Raspberry Pi.

A look under the hood
  • Java and Spring Boot backend
  • GitHub OAuth 2.0 authentication
  • PostgreSQL persistence
  • isolated Docker execution
  • automated tests and GitHub Actions
  • Checkstyle and SonarQube Cloud quality checks
  • self-hosting on a Raspberry Pi

Making room for other people

Building it alone was one kind of challenge. Making it understandable to someone else was another. I documented the architecture and added a simpler development mode so contributors could get started without recreating my home server.

Multi-Currency Telegram Bot

Our team built a Telegram bot for checking exchange rates. My part included connecting the bank APIs and caching their responses. I liked this problem: the same question shouldn’t need a fresh request to the bank every time.

QuizForger

I wanted a way to turn learning material into something people could play with. QuizForger began as my CS50 web project. You can create a quiz yourself or bring questions from an AI tool through a JSON import, then edit and share them.

Friends and people from my language course tried it and helped me see what needed changing. I built and deployed it myself, and keep it running in my Raspberry Pi homelab.

The person behind the projects

Different chapters, the same curiosity

My route here went through industrial automation and running a language centre. Working with equipment made me curious about systems. Working with learners taught me to listen, explain and notice when something that seems obvious to me isn’t obvious to someone else.

Those experiences still meet in my projects: something needs explaining, practising or simplifying, and I start wondering whether I can build something to help. My technical communications work at Smart Industry Group keeps me connected to industrial software, too.

What I’m exploring now

I’m currently improving the architecture and security boundaries of the Java Sandbox, expanding its automated tests and making it easier for other developers to contribute. I prefer learning a technology when a real project gives me a reason to use it.
