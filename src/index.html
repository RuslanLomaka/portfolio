Team projectScrum Master · Backend

Multi-Currency Telegram Bot

A team-built Java bot integrating PrivatBank and Monobank exchange-rate APIs. I worked as Scrum Master and backend contributor, implemented API integration and configurable TTL caching, and helped the team deliver a functional MVP.

Repeated user requests→cached response→bank API refreshed only after TTL expiry

Under our five-person team testing scenario, the cache was estimated to reduce upstream API requests by at least 90%, lowering the risk of rate-limit blocking.

Personal projectDesigned · Built · Deployed

QuizForger

QuizForger began as a CS50 web project and continued as a tool for creating, sharing and playing quizzes. Instead of hosting an AI model and paying for server-side tokens, I designed a reusable JSON import workflow: users can generate quiz content with the AI tool of their choice, import it and refine it in the browser.

Friends and language-course students tested the application, and their feedback influenced later improvements. I designed, developed, deployed and maintained the application myself on a Linux-based Raspberry Pi homelab.
